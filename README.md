# SchedAI

[SchedAI](https://apps.apple.com/us/app/schedai/id6777319679) is an iPhone planner that turns normal sentences into a daily schedule. A user can type or speak tasks, review the plan, set reminders, add events to Apple Calendar, and see upcoming work in a home screen widget.

I built the app with SwiftUI, including the offline task reader, scheduling system, calendar support, reminders, widgets, subscriptions, and optional AI help. The main planning tools work without sending task text to an online AI service.
