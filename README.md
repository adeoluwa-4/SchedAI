# SchedAI

## What it does

SchedAI is an iPhone planner that turns normal sentences into a daily schedule. People can type or speak tasks, set reminders, add events to Apple Calendar, and see upcoming work in a widget.

## What I built

I built the SwiftUI app, offline task reader, scheduling system, calendar support, reminders, widgets, subscriptions, and optional AI help. The main planning tools work without sending task text to an online AI service.
